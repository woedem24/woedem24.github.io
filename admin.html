Deploy to GitHub Pages
Clicking deploy will commit your changes to woedem24/woedem24.github.io and trigger a GitHub Pages rebuild. The live dashboard updates in ~30 seconds.
First-time setup guide
1
Go to GitHub → Settings → Tokens, create a token with repo scope, paste it above.
2
Enable GitHub Pages on woedem24/woedem24.github.io → Settings → Pages → Branch: main, root /.
3
Push dashboard.html, admin.html, and data.json to the repo. Your dashboard will live at woedem24.github.io/dashboard.html.
4
Whenever you earn a cert, finish a project, or update your portfolio — open this admin page, update the fields, and hit Deploy update. Dashboard updates in ~30 seconds.
5
Bookmark woedem24.github.io/admin.html — your token is saved in the browser so you never need to re-enter it.
